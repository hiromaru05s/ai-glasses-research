  - 📎 [Jetpack XR SDK core libraries reach beta: The next milestone for Android XR](https://android-developers.googleblog.com/2026/08/jetpack-xr-sdk-core-libraries-beta.html) — Android Developers Blog

  - **推測 / 含意**: Android XR ネイティブ app や PoC を持っている前提なら、秋のデバイス投入前に SceneCore / ARCore の beta02 を基準に API 追従コストを見積もる価値が高い。
