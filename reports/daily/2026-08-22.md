## 市場・業界動向（新規のみ）

- **[🟡] 英映画館業界で camera-enabled smart glasses の館内制限が公式化** — UK Cinema Association は 2026年8月20日付 statement で、Meta Glasses など wearable technology の普及を踏まえ、会員映画館の多くが privacy と film piracy の懸念から camera-enabled smart glasses の着用を禁止または制限する方針を導入しつつあると公表した。
  - 📎 [Meta Glasses and other wearable technology](https://www.cinemauk.org.uk/2026/08/meta-glasses-and-other-wearable-technology/) — UK Cinema Association
  - **事実**: UKCA の statement 公開日は **2026年8月20日** で、会員館の一部では camera-enabled smart glasses の `prohibit and/or restrict` 導入が進行している。
  - **事実**: UKCA は accessibility benefit を認めつつも、同時に privacy と film piracy を主要論点として明示した。
  - **推測 / 含意**: 法規制そのものではないが、camera-equipped AI グラスは consumer venue access の制限が先に広がる可能性があり、販売拡大には `録画可視性 / anti-tamper / venue policy interoperability` を前提にした設計説明が必要になる。

- **[🟡] ブラジルで Ray-Ban Meta 販売に対する共同調査要請が公式化** — Idec と Coding Rights は 2026年8月20日、Ray-Ban Meta のブラジル販売が LGPD と消費者保護法、女性・子ども・青少年の権利に与えるリスクを理由に、ANPD、Senacon、MPF へ coordinated investigation を要請した。
  - 📎 [Idec e Coding Rights denunciam riscos dos óculos inteligentes Ray-Ban Meta e pedem investigação no Brasil](https://idec.org.br/imprensa/denuncia-oculos-inteligentes-ray-ban-meta-privacidade) — Idec
  - **事実**: Idec 掲載文の基準日付は **2026年8月20日** で、対象当局は **ANPD / Senacon / MPF** の 3 機関と明記されている。
  - **事実**: 文書は covert recording、LED notice の不十分さ、クラウド送信と第三者レビュー、将来的な facial recognition activation リスクを争点として挙げ、Facebook Brasil Ltda. と SGH Brasil Comércio de Óculos Ltda. の調査も求めている。
  - **推測 / 含意**: Ray-Ban Meta 個別の論点だが、LatAm 展開を狙う camera-equipped AI グラス全般に対し、`privacy by design` と `non-user rights handling` を具体的に示せないと販売後に当局協調調査へ進む前例になりうる。

## Hiromaruアクションアイテム

### ①開発R&Dへのチケット候補

- **[優先度: 高] camera-equipped AI グラス向けの venue / regulator 受容性チェックリストを更新する** — `録画インジケーターの可視性`, `anti-tamper`, `第三者の権利行使窓口`, `cloud review / training data flow`, `禁止エリア運用` を 1 枚にまとめたい。📎 [Meta Glasses and other wearable technology](https://www.cinemauk.org.uk/2026/08/meta-glasses-and-other-wearable-technology/) / 📎 [Idec e Coding Rights denunciam riscos dos óculos inteligentes Ray-Ban Meta e pedem investigação no Brasil](https://idec.org.br/imprensa/denuncia-oculos-inteligentes-ray-ban-meta-privacidade)
- **[優先度: 中] LatAm 展開想定の privacy-by-design 論点を棚卸しする** — 非ユーザーが自分の画像・音声データの扱いを確認・削除請求できる導線を用意しない設計は、販売後の当局協調調査リスクを高める。📎 [Idec e Coding Rights denunciam riscos dos óculos inteligentes Ray-Ban Meta e pedem investigação no Brasil](https://idec.org.br/imprensa/denuncia-oculos-inteligentes-ray-ban-meta-privacidade)
- **[優先度: 低] SDK / build 監視は現状維持** — Apple visionOS と Android XR の公開面には 2026年8月22日時点で独立した新 build / 新 API 差分はなかった。📎 [Releases](https://developer.apple.com/news/releases/) / 📎 [Jetpack XR SDK core libraries reach beta: The next milestone for Android XR](https://android-developers.googleblog.com/2026/08/jetpack-xr-sdk-core-libraries-beta.html)

### 判断が必要な事項

- **go-to-market 監視で venue policy を独立トラック化するか** — 今回の UKCA 公表のように、法改正前でも商業施設の運用制限が先行しうる。
- **camera visibility をデザイン要件としてどこまで固定するか** — ブラジル文脈では LED notice の視認性と改変耐性が主要争点になっている。

### coworker共有推奨

- **本日の純新規 2 件はどちらも regulation / trust 側** — hardware / SDK ではなく、AI グラスが社会的にどこまで許容されるかの条件が更新された日だった。
- **秋商戦の実務論点は「売れるか」より「どこで使えて誰に説明責任を負うか」へ拡張している** — cinema venue 制限と当局調査要請は、その変化を示す具体例である。
